# Fluxos dos agentes (fonte: fluxos-agentes.docx)

1. **Navegante (pessoa):** com Ethos concluído, vai ao dashboard; sem concluir, volta ao Ethos no ponto em que parou.
2. **Porto (território):** igrejas, escolas, associações, iniciativas. Cada porto tem um CEP; o CEP dos portos em que o navegante se inscreve entra no dashboard dele (portos, vagas e cursos).
3. **Trilha (cursos):** somente instituições cadastram cursos e trilhas, remotos ou em locais determinados.
4. **Destino (empresas):** vagas para pessoas próximas, com as competências necessárias. CEP e CNAE geram o mapa georreferenciado; compram cotas de vagas; dados de impacto só para uso interno.
5. **Apoiador (mantenedor):** mesmas atividades do Destino, mais cotas de recursos para investir nos portos. Dados de impacto alimentam o dashboard do apoiador, para uso interno e, depois, campanhas digitais.
