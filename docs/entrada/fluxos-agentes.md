# Fluxos dos agentes (fonte: fluxos-agentes.docx)

1. **Entrada:** oferece somente duas escolhas: Navegante ou Porto. A escolha encaminha para a área correspondente ao perfil autenticado.
2. **Navegante (pessoa):** acessa uma página com seus portos, cursos e vagas. Com Ethos concluído, permanece no dashboard; sem concluir, volta ao Ethos no ponto em que parou.
3. **Porto (território):** acessa um dashboard com suas vagas, cursos e iniciativas, além de um mapa dos demais portos. Portos incluem igrejas, escolas, associações e iniciativas, e cada um tem um CEP.
4. **Trilha (cursos):** somente instituições cadastram cursos e trilhas, remotos ou em locais determinados.
5. **Destino (empresas):** vagas para pessoas próximas, com as competências necessárias. CEP e CNAE geram o mapa georreferenciado; compram cotas de vagas; dados de impacto só para uso interno.
6. **Apoiador (mantenedor):** mesmas atividades do Destino, mais cotas de recursos para investir nos portos. Dados de impacto alimentam o dashboard do apoiador, para uso interno e, depois, campanhas digitais.
